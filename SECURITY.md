# Segurança

Achou uma falha de segurança no Mago OS? Obrigado por avisar.

- **Não abra uma issue pública.** Use o botão **"Report a vulnerability"** na aba **Security** deste repositório
  (aviso privado, só os mantenedores veem).
- Diga o que encontrou, como reproduzir e o que dá para fazer com isso. Não acesse dados de outras pessoas além do
  necessário para mostrar a falha, e não derrube o sistema.
- Respondemos em até 3 dias úteis e avisamos quando a correção estiver publicada.

Como o Mago OS cuida da segurança: `docs/operacao/revisao-de-seguranca-fase-1.md` e `docs/operacao/incidente.md`.
